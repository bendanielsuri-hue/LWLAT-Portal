{% comment %} The preset-reason control: a dropdown of the admin-managed PresetReason rows for one context, plus an "Other" option that reveals a free-text box. Wired by panel/js/components/preset-reason-field.js, which finds every part by the data- attributes below rather than by id, so several of these can render on one page (the Panel Group modal renders one inside a form that already shares the dialog with the member rows' own forms). Params: presets (the PresetReason rows for this context), field_id_suffix (unique per instance - only the label/control pairing uses it), label (defaults to "Reason"), required (bool). The "__other__" value is reasons.OTHER, written out here the same way form_action literals are - see reasons.py for the contract. {% endcomment %}
