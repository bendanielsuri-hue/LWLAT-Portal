{% comment %} Disabled-button + tooltip wrapper. .btn-disabled sets pointer-events:none (buttons.css), which suppresses hover entirely - a `title` on the disabled element itself never shows a tooltip, so it has to sit on a plain wrapping element that still receives hover instead. `title` is optional: omit it when the label alone is explanation enough. Params: classes (extra .btn modifier classes, e.g. "btn-secondary btn-sm"), icon (icon template path, optional), label (button text), title (tooltip text, optional). {% endcomment %} {% if title %}{% endif %} {% if icon %}{% include icon %} {% endif %}{{ label }} {% if title %}{% endif %}
